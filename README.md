# מרוץ החבילות (Packet Run)

משחק מרוצים בעולם פתוח (Three.js) ללימוד **פרוטוקולים ומודלים** (חוקי תקשורת, OSI, TCP/IP, כימוס) לכיתה י״א, מגמת תקשוב.
נוסעים בעיר חופשית בשבע שכונות, מתחרים, אוספים, משדרגים רכב (מנוע, נייטרוס, גלגלים, וינילים), זורקים פריטים על הכביש, ולומדים בשלושה מוסכי שיעור (שיעור, חידון ומשחקון בשלוש רמות). אחרי כמה דקות נסיעה נגמר הדלק והגרר מביא אל השיעור הבא.

- פיתוח: `npm install`, `npx vite --port 5211`, בדיקות `npx vitest run`, טיפוסים `npx tsc --noEmit`, בנייה `npm run build`.
- מסמכי תכנון בריפו הראשי של הפרויקט: `specs/packet-run/` (`00_DESIGN.md`, `01_CONTRACT.md`).
- אמנות: `art/README.md` (Blender 5.2 -> glTF).
